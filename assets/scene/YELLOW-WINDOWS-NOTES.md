# Yellow shophouse windows

The two upstairs windows and the ground-floor window have independent native
buttons. The existing shutters and grille panels rotate inward to expose a
shaded interior. Closing restores the original scene. The plant stays in front
of the ground-floor opening. Light switches use the decorative panels above
the windows and remain independent of opening or closing them.

The built-in image tool generated `yellow-window-interior.png` from the exact
prompt in `yellow-window-interior.prompt.txt`. The original generated image is
`exec-e53986ad-71df-4dda-a72c-01ffec0f16fb.png`. The web export is 256 by 384
pixels. The renderer shades it for daylight and the selected room-light state.
All shutter and grille textures come from the existing scene artwork.

Verification: all 126 tests pass. Browser checks cover all three windows in
day/night on desktop and mobile, exact restoration after closing, independent
light switches, animation reversal, and 320-pixel touch targets.
